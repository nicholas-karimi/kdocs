Where should configuration come from?
Approaches
1. Hardcoded
Addr: ":8080"
-simple but inflexible

2. Configuration File
server:
  address: ":8080"
-Useful in some applications, but introduces another file format and configuration mechanism.

3. Environment variables
KDOCS_ADDR=:8080
then Go reads the value
-use environment variables for runtime configuration.- a very common approach for web applications and will become especially useful when we have PostgreSQL and authentication.

export KDOCS_ADDR=:8081

in Go

gofmt - Go's standard code formatter. It automatically formats Go source code according to Go's standard formatting rules.
> gofmt -w internal/web/router.go cmd/kdocs/main.go
gofmt       → format Go code
-w          → write the formatted result back to the files
file1 file2 → format these files
Without -w, gofmt would print the formatted version to the terminal instead of modifying the files.

We Go devs loves it coz instead of arguing about
tabs vs spaces
brace placement
line breaks
import formatting

the formatter settles it.

shortcut
